# codeTurnip website

Static pages for [codeTurnip](https://crash1604.github.io/codeturnip/): home, Terms of Service, and Privacy Policy. They are referenced by the codeTurnip Publisher's TikTok and Meta developer apps.

- `index.html`, `terms.html`, `privacy.html`, `styles.css`: the pages (no JavaScript, cookies, or analytics)
- `icon-1024.png`: app icon for developer portals
- TikTok URL-prefix verification files are added at the site root when TikTok issues them

Source of truth: `automation/social-publishing/website/` in the codeTurnip production repository.
